よみときコード 読む・直す・守る・学ぶ、じぶん専用の学習ノート
NOTE / 02

学ぶ ― 土台をつくる

AI×業務効率化エンジニアのロードマップに沿った基礎知識です。カードを開いて読み、理解度チェック(選択式・全問アプリ内蔵)で確認しましょう。

読む ― コードに注釈をつける

読めないコードを貼り付けると、意味のまとまりごとに注釈をつけて解説します。

直す ― 原因を突き止める

コードとエラーメッセージを貼り付けると、原因の仮説と直し方、再発防止のヒントを出します。

守る ― 危ないところを見つける

コードを貼り付けると、よくある脆弱性や設計上のリスクを指摘します。

コラム ― 外の世界で学ぶ

アプリの外にも良質な教材はたくさんあります。使える時間に合わせて選んでください。

☕ すきま時間に(〜15分)

通勤中や子どもの昼寝タイムなど、短い時間でサッと読める・見られるもの。

ドットインストール

1本3分の動画でプログラミングを学べる日本のサービス。JavaScript基礎の講座から始めるのがおすすめ。1本だけ見る、が続けやすい。

1本 約3分日本語初級〜中級

MDN Web Docs

Mozillaが運営するWeb技術の公式リファレンス。「読む」タブで出てきた用語を調べる辞書として使うのが◎。1記事5〜15分。

1記事 5〜15分日本語初級〜上級

JavaScript.info(日本語版)

JavaScriptを体系的に、丁寧に解説した教科書サイト。1章10〜20分。ロードマップのSTEP1〜3の内容がほぼカバーされている。

1章 10〜20分日本語初級〜中級

Zenn / Qiita

日本のエンジニアによる技術記事サイト。「fetch API 使い方」など具体的な悩みで検索すると実例つきの記事が見つかる。1記事5〜10分。

1記事 5〜10分日本語初級〜上級

📚 まとまった時間に(1時間〜)

休日など、腰を据えて学べるときに。理解が一段深まるものを揃えました。

CS50(ハーバード大学)

ハーバード大学が無料公開しているコンピュータサイエンス入門講義。YouTubeで全講義が見られる。メモリやデータ構造など「コードの裏側で何が起きているか」の理解が深まる。英語だが日本語字幕あり、有志の日本語翻訳サイト(cs50.jp)も存在する。

1講義 90〜120分英語(日本語字幕あり)初級〜中級

Progate

ブラウザ上で手を動かしながら学べる日本のサービス。環境構築不要でスライド+演習形式。基礎の復習・穴埋めに最適。無料枠あり。

1レッスン 30〜60分日本語初級

freeCodeCamp

無料で演習中心に学べる海外の定番サービス。JavaScriptアルゴリズムのコースは実力がつくと評判。YouTubeチャンネルの長編チュートリアルも豊富。

1セクション 1〜3時間英語初級〜中級

roadmap.sh

エンジニアの学習ロードマップ集。「Frontend」「JavaScript」「AI Engineer」「Backend」を眺めて、自分の現在地と次に学ぶことを確認するのに使う。地図として月1回見返すのがおすすめ。

眺めるだけなら15分英語全レベル

IPA「安全なウェブサイトの作り方」

情報処理推進機構(IPA)が無料公開しているセキュリティの定番資料。XSSやSQLインジェクションなど主要な脆弱性と対策が日本語でまとまっている。「守る」タブの内容を深掘りしたいときに。

通読 2〜3時間日本語初級〜中級
