# よみときコード

読む・直す・守る・学ぶ、じぶん専用のプログラミング学習ノート。

Claude.ai の artifacts 機能で作成した、単一HTMLファイルの学習アプリです。

- **公開URL**: https://yomitoki-code.vercel.app (Vercel / mainブランチ連動)
- **リポジトリ**: https://github.com/blancat00/yomitoki-code

## 機能

| タブ | 内容 | AI |
|------|------|----|
| CH.01 学ぶ | AI×業務効率化エンジニアのロードマップに沿った20テーマの教材 + 内蔵クイズ(各2問・選択式) | 不要 |
| CH.02 読む | カメラでコードを撮ると、用語マスタに載っている単語に下線+吹き出しで解説(端末内OCR) | 不要 |
| CH.03 直す | コード+エラーを貼り付けると、原因の仮説・仕組み・直し方・再発防止策を提示 | 必要 |
| CH.04 守る | コードの脆弱性(XSS・SQLi・秘密情報など)をリスクレベル付きで指摘 | 必要 |
| CH.05 コラム | 外部学習リソース集(所要時間・言語・レベル表記付き) | 不要 |

### 用語ホバー解説

コードブロック内の単語(`const`、`fetch`、`=>`、`border-radius` など)にマウスをかざすと、`glossary.js` の用語マスタ(約490語)を参照して解説ツールチップが表示されます。マスタはJS/HTML/CSS/HTTP・API/SQL/Python/Git/AI/セキュリティ用語をカバーしており、`glossary.js` に1行足すだけで語彙を増やせます。

### 読む ― カメラで用語をよみとく(AIなし)

カメラを本・画面・紙のコードにかざして撮ると、端末内OCR(Tesseract.js)で文字を読み取り、用語マスタに載っている単語へ下線を引きます。下線をタップすると、下線から棒が伸びて解説の吹き出しが表示されます。AI・サブスク認証は不要なので出先でも使えます(OCRエンジンの初回読み込みのみ通信が必要)。カメラを使うためHTTPS(公開URL)での利用推奨。

## 使い方

- **claude.ai の artifacts 内**: そのまま動作します(AI呼び出しは追加課金なし)
- **ローカル / GitHub Pages / Vercel**: 「学ぶ」「読む」「コラム」タブは完全動作します。「直す」「守る」のAI機能は動きません(下記の重要事項を参照)

## ⚠️ 移行時の重要事項

このアプリのAI呼び出しは、claude.ai の artifacts 環境専用の仕組みに依存しています。

1. **AI API**: `https://api.anthropic.com/v1/messages` へ APIキーなしで fetch していますが、これは artifacts 内でのみ有効です。外部環境では認証エラー/CORSエラーになります。外部で動かす場合は、APIキーを保持するバックエンド(プロキシサーバー)が必要です。**APIキーをフロントエンドに直書きしないでください**(このアプリの「守る」教材で教えている通りです)。
2. **データ保存**: artifacts の `window.storage` が存在しない環境では、自動的に `localStorage` にフォールバックするシムを組み込み済みです(キー接頭辞 `yomitoki:`)。

詳細な開発引き継ぎ情報は `CLAUDE.md` を参照してください。
